Quick Commands
==============
Setup:
  pip install -r requirements.txt
  python test_setup.py
  python create_icp_template.py

Run:
  python main.py                              # Standard run
  python main.py --max-companies 2 --max-profiles 2   # Test run
  python main.py --schedule                   # Scheduled mode

Maintenance:
  python validate_config.py                   # Check config
  python utils_clear_new_flags.py             # Clear flags
  cat logs/sdr.log                            # View logs
